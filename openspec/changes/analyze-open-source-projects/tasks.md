# Tasks

Rules for every task (see `handoff/haiku-rules.md`): edit only the files named, copy the pattern of the existing code named, run the verify command, tick the box, and stop and report if blocked. Backend commands run in `backend/`, UI commands in `ui/` (use `npx`, pnpm is not installed). The Contract is in `design.md`: types and JSON are fixed, do not rename them.

Groups 1, 2 and 3 are independent and can run in parallel (they share only the Contract; group 1 owns `profile/Profile.kt`, the others add their own files and, where they need a type from the Contract that is not merged yet, add it as a stand-in and report it). Group 4 needs 1, 2 and 3 merged. Group 5 (UI) needs group 1 merged for the fixture; it can start in parallel from the Contract.
