# Tasks

Rules for every task (see `handoff/haiku-rules.md`): edit only the files named, copy the pattern of the existing code named, run the verify command, tick the box, and stop and report if blocked. Backend commands run in `backend/`, UI commands in `ui/` (use `npx`, pnpm is not installed). The Contract in `design.md` is binding: names, types and JSON are fixed. Test data is synthetic (an invented person such as "Ada Example"); never use real personal data.

Groups 1, 2, 3, 5 and 6 are independent and can run in parallel. Group 3 needs the document model of group 2: it adds a stand-in file `cv/export/StandInDocumentModel.kt` with exactly the Contract's types and reports it; the lead deletes it at merge. Group 4 needs 1, 2 and 3 merged. Group 7 comes last.
