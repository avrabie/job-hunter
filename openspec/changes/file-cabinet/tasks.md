## Contract (do not change)

File details JSON: `{"id":"<uuid>","name":"…","kind":"CV"|"OTHER","contentType":"…","sizeBytes":123,"uploadedAt":"2026-10-23T10:00:00Z","master":false}`.
Ticket answer: `{"path":"/api/files/<uuid>/content?ticket=<hex>"}`. Master request: `{"fileId":"<uuid>"}`.
Errors are `{"error":"invalid_file","message":"<fixed text>"}` with statuses 400, 404, 413, 507 as in the specs. Fixed texts: wrong type "The file must be a PDF, a Markdown file or a plain text file."; too large (CV) "The file is larger than 5 MB."; too large (other) "The file is larger than 10 GB."; disk "The server has no room for this file right now."
